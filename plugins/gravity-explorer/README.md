# 引力目录 (`gravity-explorer` v2.1.0)

**引力目录 (Gravity Explorer)** 是面向 Google Antigravity 桌面端的项目目录浏览器，基于 **纯 Node.js 22+（ESM + `sidecar_sdk`）** 构建，融合 macOS 访达（Finder）四栏列表效率与 Google Gemini 五色双主题视觉。

## 核心能力
- **macOS 访达四栏列表视图**：展示 `名称 | 修改日期 | 大小 | 种类`，搭配舒适行高、立体水蓝文件夹图标与彩色文稿角标、圆角奇偶斑马纹与底部路径面包屑。
- **轻量内置预览抽屉**：单击即可在底部分栏秒开语法高亮（JS/TS/JSON/HTML/CSS/Python/Go/Rust/Shell/SQL/YAML）、Markdown 排版、CSV 表格及透明棋盘格图片预览（含 `W × H` 像素尺寸）。
- **原生标签页直开**：双击任意可读文件或点击 `↗` 按钮，直接在 Antigravity 主标签页/分栏中打开。
- **拖拽与快捷操作**：支持多选（`Cmd/Ctrl + Click`、`Shift + Click`）、跨窗口拖拽 `@引用` 至对话输入框、一键复制 `@相对路径` 或绝对路径、在访达/资源管理器显示、系统默认软件打开与安全移至废纸篓/回收站。
