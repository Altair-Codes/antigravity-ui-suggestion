# 引力文库 (`gravity-vault`)

- 在扩展列表打开右侧面板「引力文库」即可查看按 **当前会话 / 当前项目 / 全部范围** 精确隔离的交付文件与 `@` 引用记录。
- 支持一键 **复制引用**（`@文件名（完整路径）`）、**`★` 收藏**（写入防压缩保护清单）与 **按日归档**（`YYYY-MM-DD/文件名`，自动重名避让不覆盖历史归档）。
