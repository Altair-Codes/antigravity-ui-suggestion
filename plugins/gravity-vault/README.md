# 引力文库 (`gravity-vault` v2.2.0)

**引力文库 (Gravity Vault)** 是面向 Google Antigravity 桌面端的会话文档与交付物管理扩展，基于 **纯 Node.js 22+（ESM + 原生 `node:sqlite`）**，冷启与热刷新响应均在毫秒级。

## 核心能力
- **三层精准隔离 (`node:sqlite` + 增量扫描)**：只读解析会话索引与活跃会话记录/产物，精确隔离 **当前会话**、**当前项目** 与 **全部范围**。
- **来源 × 类型复合筛选**：快速筛选「交付/生成」「已修改」「我发送的（`@` 引用与上传附件）」「★ 收藏」以及文档、Markdown、表格、演示、PDF、图片或代码类型。
- **极速预览与分栏直开**：点击文件名默认在 Antigravity 右侧 `fileView` 分栏直开；二进制或自定义格式支持内置轻量预览弹窗或一键调用系统默认软件打开。
- **一键 `@引用` 复制 & 与历史目录联动**：单行与多选批量支持复制 `@文件名（完整路径）`；支持 **`★` 防压缩收藏清单**（同步写入 `PINNED_FILES_MANIFEST.md`，并与引力中枢「历史目录」实时联动标注 `★文库`）与 **按日整理**（`YYYY-MM-DD/filename`，重名自动追加 `(2)` 后缀）。
- **零弹窗与轻量常驻规则**：绝不在对话回复后自动弹出侧边栏或注入内嵌卡片外壳；[`rules/AGENTS.md`](./rules/AGENTS.md) 已瘦身为紧凑静态条目以减少每轮上下文开销。
